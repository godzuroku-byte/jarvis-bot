# J.A.R.V.I.S. — исправленная сборка

Телеграм-бот на Python с Gemini, командами, обработкой медиа, админ-панелью и памятью.

## Что исправлено

- Заменена устаревшая модель Gemini 2.0 Flash на актуальную модель по умолчанию `gemini-3.8-flash`.
- Добавлен автоматический перебор резервных моделей, если выбранная модель недоступна.
- Вызовы Gemini переведены на асинхронный SDK, чтобы долгий запрос меньше блокировал Telegram-бота.
- Добавлены тайм-ауты и ограничение одновременных запросов.
- Ошибка больше не маскируется только общим сообщением: подробная безопасная диагностика доступна владельцу через `/diagnostics`.
- Временные файлы медиа удаляются даже при ошибке загрузки.
- Добавлены `/ping`, `/model`, `/diagnostics`.
- Улучшена обработка повреждённого `config.json` и экранирование динамического HTML в нескольких ответах.
- Существующие команды и обработчики оставлены.

## Требования

Python 3.11+ и переменные окружения:

- `BOT_TOKEN` — токен Telegram-бота.
- `GEMINI_API_KEY` — ключ Gemini API.
- `OWNER_ID` — ваш числовой Telegram ID.
- `GEMINI_MODEL` — необязательно, по умолчанию `gemini-3.8-flash`.
- `GEMINI_FALLBACK_MODELS` — необязательно, по умолчанию `gemini-3.7-flash,gemini-2.5-flash`.
- `GEMINI_TIMEOUT_SECONDS` — необязательно, по умолчанию 60 секунд.
